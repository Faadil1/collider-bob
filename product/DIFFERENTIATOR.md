# Differentiator

## Crowded territory we do not claim
semantic merge; shared agent memory; generic conflict detection; multi-agent review; decision ledger; context leases; automated clarification alone.

## COLLIDER wedge
Independent implementation agents are used as ambiguity probes.

When agents make incompatible choices:
1. retrieve source evidence
2. determine whether one contradicted an explicit requirement
3. if yes → AGENT_DRIFT
4. if the source does not decide the question and multiple interpretations remain plausible → SPEC_GAP / UNKNOWN
5. ask the minimum clarification
6. persist the answer as a canon patch
7. invalidate/replan only workstreams that depend on the decision

## Novelty sentence
COLLIDER does not merely detect that agents disagree; it uses disagreement to discover decisions the specification never made.

## Kill condition
If a competitor demonstrates this full loop — independent implementation interpretations → source-aware AGENT_DRIFT vs SPEC_GAP classification → minimal clarification → dependency-aware targeted repair — re-open Concept Lock before submission.
