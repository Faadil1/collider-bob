## What this proves

Observed:

- COLLIDER executes inside a real GitHub pull-request workflow.
- The same gate produces all three product verdicts:
  `MERGE_ALLOWED`, `MERGE_BLOCKED`, `DECISION_REQUIRED`.
- The workflow posts the semantic verdict directly into the PR.
- The workflow exposes conventional workstream-test results beside the semantic
  verdict.
- `DECISION_REQUIRED` can occur while all 30 conventional workstream tests pass.
- `MERGE_BLOCKED` can cite an existing canonical decision as authority.
