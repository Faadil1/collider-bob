# Demo Contract

## Judge Memory Sentence
Three agents can be individually right and still reveal that the specification forgot to decide.

## Signature Behavior
Independent Bob subagents become ambiguity probes.

## Signature Moment
Local workstreams look valid, but COLLIDER reveals that the source never defines the durable customer identity. It returns SPEC_GAP / UNKNOWN instead of inventing an answer, asks one minimal question, then reroutes only affected work.

## Canonical scenario
Brief:
"After a failed charge, credit the customer and notify them."

Workstreams:
- API
- Ledger
- Notifications

Planned disagreement examples:
- durable identity: email vs account_id
- money transport representation: decimal dollars vs integer cents

At least one disagreement must be a genuine SPEC_GAP in the fixture.
At least one separate fixture claim must be explicitly specified so AGENT_DRIFT can be demonstrated.

## Proof
Do not preset improvement percentages.
Capture baseline and COLLIDER runs, then report observed:
- human clarifications
- rework cycles
- workstreams rerun
- time to integration-ready
- contradictions surfaced before integration

## Negative path
When evidence cannot distinguish plausible interpretations:
SPEC_GAP → UNKNOWN → HUMAN DECISION REQUIRED
